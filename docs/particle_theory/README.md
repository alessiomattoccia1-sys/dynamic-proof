# Particle Theory

The fourth Dynamic Proof laboratory uses the shared lab catalogue, runner, SQLite registry, evidence classes, and reporting. Its first programme studies left-handed Weyl fermions with integer charges in an isolated U(1) sector and masses generated by renormalizable Yukawa couplings.

## Getting started

Run from the checkout with Python 3.12.

~~~sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m dynamic_proof --state .local/particle-research init --lab particle_theory
.venv/bin/python -m dynamic_proof --state .local/particle-research run --lab particle_theory --cycles 30
.venv/bin/python -m dynamic_proof --state .local/particle-research status
.venv/bin/python -m dynamic_proof --state .local/particle-research serve --lab particle_theory --port 8791
~~~

The dashboard listens on loopback. The Particle Theory section shows active problems, outcomes, search progress, and mass matrices. Open a result in the registry to inspect its dependencies. [Local dashboard](http://127.0.0.1:8791/)

## JSON problems

~~~sh
.venv/bin/python -m dynamic_proof --state .local/particle-research submit particle_theory experiments/particle/PT-006.json
.venv/bin/python -m dynamic_proof --state .local/particle-research run --lab particle_theory --cycles 10
~~~

| Field | Meaning |
| --- | --- |
| `id`, `title` | Problem identifier and title. |
| `type` | `classification`, `construction`, `counterexample`, or `proof`. |
| `fermions`, `charge_bound` | Fermion count from 1 to 10 and absolute charge bound from 1 to 32. Zero charges are excluded. For proof problems these fields bound the counterexample search. |
| `fermion_charges` | Optional fixed charge vector. Permutations and global sign reversal represent the same input. |
| `anomalies` | Defaults to `["linear","cubic"]`. Select a subset to study individual conditions. |
| `strict_chirality`, `primitive` | Both default to `true`. They exclude opposite charge pairs and require a greatest common divisor of one, respectively. |
| `scalar_charges` | Optional list of nonzero integer charges. A scalar and its conjugate yield the same support. When omitted, the pool contains all nonzero absolute fermion-pair sums. |
| `max_scalars`, `mass_condition` | Maximum number of distinct scalar charges. `full_rank` requires an invertible witness. `any` accepts any rank. With `any` and a zero limit, only fermion constraints are checked. |
| `method` | `enumeration` visits all multisets. `quadratic` reduces the last two charges and requires both anomaly conditions. |
| `theorem` | For proofs, select `odd_scalar_valuation`, `two_scalar_labels`, or `one_scalar_multiple_four`. Counterexample problems test whether the arithmetic condition suffices for the given scalar set. |
| `completeness` | `exhaustive` for classification and proof. `witness` for counterexamples. Construction accepts either. |
| `references` | Source identifiers from the Particle Theory catalogue. Provenance includes the Costa, Dobrescu, and Fox papers. |
| `budget` | `steps_per_cycle`, `max_steps`, `max_models`, `smt_ms`, `verification_steps`, and `scalar_sets`. Configure wall time, CPU, RAM, and daily quota in the runner's TOML. |

The queue stores normalized input. Resubmitting the same problem with permuted or globally reversed charges and otherwise identical fields produces the same job key. Each checkpoint stores the classes found and the cursor for the next slice. An interrupted slice can be recomputed from the latest checkpoint.

## Research programme

- **PT-001** reproduces the pilot domain. **PT-002** checks every one-scalar support and constructs a two-scalar mass witness.
- **PT-003** verifies the parity theorem for arbitrary matrix size. **PT-004** increases the fermion count and absolute charge bound.
- **PT-005** combines chirality, anomalies, and full rank for a fixed scalar pool. **PT-006** tests the scope of the necessary arithmetic condition.
- **PT-007** derives a constraint on scalar charge ratios for odd fermion counts. **PT-008** checks a finite four-fermion case with no solutions.
- **PT-009** explores the next odd fermion count. **PT-010** checks whether the six-fermion models in the stated domain admit full mass rank with one scalar.
- **PT-011** derives divisibility by four under the fixed-point assumption for the two charge reflections. **PT-012** constructs a full-rank eight-fermion model using two equal sums of two squares.

Experiment files declare constraints before execution. PT-005 bounds the scalar pool to 1–6 to limit the number of supports. PT-006 holds the ratio at 1:2 and changes its scale relative to the pilot. PT-010 tests the even case, where the PT-003 parity argument leaves invertibility open.
